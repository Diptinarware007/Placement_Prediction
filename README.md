# Student Placement Prediction System Using Machine Learning

## 📌 Project Overview
The Student Placement Prediction System is a machine learning-based project designed to predict whether a student is likely to be placed or not placed based on academic performance and skill-related factors.

The project uses machine learning algorithms to analyze student information and generate placement predictions. A user-friendly web application is developed using Streamlit, allowing users to enter student details and view the prediction.

## 🎯 Objectives
- To analyze student academic and skill-related information.
- To apply machine learning algorithms for placement prediction.
- To train and evaluate classification models.
- To develop an interactive web application using Streamlit.
- To demonstrate how machine learning can support placement-readiness analysis.

## 🛠️ Technologies Used
- **Python** – Main programming language.
- **Jupyter Notebook** – Model development and experimentation.
- **Pandas & NumPy** – Data processing.
- **Matplotlib & Seaborn** – Data visualization.
- **Scikit-learn** – Machine learning model training and evaluation.
- **Logistic Regression** – Classification algorithm.
- **Decision Tree** – Classification algorithm.
- **Streamlit** – Web application development.
- **Joblib** – Saving and loading the trained model.

## 📊 Dataset Description
The project uses a simulated student dataset containing academic and skill-related features, such as:
- CGPA
- Number of Internships
- Aptitude Test Score
- Communication Score
- Number of Projects
- Certifications
- Placement Training

**Target Variable:** Placement Status (Placed / Not Placed).

## ⚙️ Project Workflow
1. Dataset collection and loading.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Splitting data into training and testing sets.
5. Training Logistic Regression and Decision Tree models.
6. Model evaluation and comparison.
7. Saving the trained model using Joblib.
8. Developing the Streamlit web application.
9. Deploying the application online.

## 🚀 How to Run the Project Locally

**Step 1: Clone the repository**
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the project folder**
```bash

```

**Step 3: Install dependencies**
```bash
pip install -r requirements.txt
```

**Step 4: Run the Streamlit application**
```bash
streamlit run app.py
```
